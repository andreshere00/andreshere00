\begin{frame}{SplitterMR}
  Library with four building blocks: \textbf{Readers}, \textbf{Models \&
  embedders}, and \textbf{Splitters}.

  \begin{itemize}
    \item Readers extract file content to Markdown (Docling, MarkItDown, or a
          custom base class).
    \item Splitters chunk by characters, grammar, tokens, code separators,
          semantic similarity, or schema.
    \item Visual Language Models read scans, images and tables
          (OpenAI, Anthropic, Hugging Face, Gemini, Grok, or BYO model).
  \end{itemize}

  \begin{exampleblock}{Status}
